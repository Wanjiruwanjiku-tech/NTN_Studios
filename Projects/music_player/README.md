# 🎧 Project: Python Music Player

1. 🧰  Prerequisites

- Make sure you have Python 3.8+ installed.

- You’ll also need:

  - tkinter – for GUI (comes pre-installed with Python)

  - pygame – for playing audio

  - os – for file management

- Install pygame:

    bash
    pip install pygame

2. 🗂️ Project Structure

- Create a folder for your app:

    music_player/
    │
    ├── main.py
    ├── music/          # a folder to store your .mp3 files
    └── icon.png        # optional app icon

3. 🧠 Basic Idea

- We’ll use:

    - Tkinter for GUI buttons (Play, Pause, Next, Previous)

    - Pygame Mixer to handle music playback

    - Listbox widget to display the playlist.
