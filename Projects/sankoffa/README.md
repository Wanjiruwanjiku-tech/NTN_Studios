# The seed of sankoffa story voiceover  carousel
----------------------------------------------------------

## Project Concept
--------------------------------------------------------------------

### Core Features:

1. Horizontal or Vertical scrollable sections each with a scene from the story.
2. CSS animations for mood, like fading embers, glowing sankoffa symbols or shifting sky tones.
3. JavaScript audio triggers that play voice overs when the scene enters view.
4. __Optional__: A floating Sankoffa icon that glows brighter as the story progresses.

### Tools

1. __HTML__
- To structure the carousel and content blocks

2. __CSS__
- To animate backgrounds, control layout and add atmosphere

3. __JavaScript__
- To handle scroll events, play and pause voiceovers and optionally add scene progress tracking.
